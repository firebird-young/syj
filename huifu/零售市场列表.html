零售市场列表 · 功能说明

1、自选 1

  • 在「推荐」前增加「自选」标签列，展示用户加为自选的产品列表
  • 用户可在产品详情页点击「加为自选」按钮，将产品加入自选列表，方便快速查看与再次购买

2、搜索

  • 顶部搜索框支持按 产品名称 / 产品编码 模糊匹配，输入即时过滤，也可点「搜索」按钮触发
  • 无匹配结果时列表区展示空状态提示

3、标签栏

  • 自选 / 推荐 / 全部 / 鉴赏 / 活动 / 期待 / 典 为内容分类切换（原型中为切换高亮演示）
  • ▲价格：点击按「当前最低价」升序排列，再次点击变 ▼价格 降序排列；暂无挂单的产品始终排在最后

4、产品列表

  • 每行展示：产品图、产品名称、产品编码
  • 有挂单时右侧显示「当前最低价 + 价格」（主色突出）；无挂单时显示灰色「暂无挂单」
  • 点击整行进入零售市场详情（产品详情）

5、底部导航

  • 批发市场 / 共享超市（当前页） / 我的 三个入口，原型中点击可跳转或提示
