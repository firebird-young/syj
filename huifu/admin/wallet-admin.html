平台 · 系统配置

1 钱包列表

  • 展示平台已接入的第三方支付钱包：logo、钱包名称、创建时间、启停状态
  • 钱包状态以标签展示：启用（绿）/ 停用（红）

2 新增 / 修改钱包

  • 点击右上角新增钱包或操作列修改，打开钱包编辑弹窗
  • 填写钱包名称（必填）、上传平台 logo、编辑开通说明（支持富文本：加粗 / 斜体 / 列表 / 对齐等）
  • 开通说明将在用户侧开通该钱包时展示

3 查看钱包

  • 点击操作列查看，以只读模式打开弹窗：名称、logo、开通说明均不可编辑

4 启用 / 停用

  • 操作列开关切换钱包启用 / 停用，切换后列表状态标签实时更新
  • 停用的钱包不再出现在 C 端开通入口，已开通用户不受影响
