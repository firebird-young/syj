功能说明

一、页面定位

  • 展示平台「零售市场订单」明细，支持按订单编号、买家/卖家账号、产品名称、订单状态等维度筛选
  • 覆盖 宝付钱包 与 汇付钱包 两个支付渠道的订单记录

二、字段说明

  • 基础字段：订单编号、支付渠道订单号、产品名称、产品编号、买家/卖家账号、数量、单价
  • 金额字段：买家实付、买家手续费、卖家手续费、第三方支付手续费、平台交易手续费、服务商手续费、卖家所得金额
  • 状态与归属：订单状态（待成交 / 已成交 / 已撤销 / 撤销部分成交 / 异常订单）、是否提货、服务商、支付产品、支付渠道、时间
  • 支付渠道：宝付 / 汇付
  • 支付产品：原"支付渠道"重命名而来（银行卡 / 余额）

三、产品编号

  • 产品名称后新增 产品编号 列，仅 汇付钱包 订单填写（每笔订单对应 1 个编号）
  • 宝付钱包 订单产品编号留空，显示 —
  • 编号过长时单元格自动截断显示省略号，鼠标悬停 显示完整编号

四、金额计算规则（按支付渠道区分）

  • 汇付支付：买家实付 = 单价 × 数量；卖家实付 = 单价 × 数量（与买家实付一致）；买家手续费 = 0
① 卖家手续费 = 买家实付 × 1.6%（向上取整到分）
② 第三方支付手续费 = 买家实付 × 0.6%（向上取整到分）
④ 平台交易手续费 = 卖家手续费 − 第三方支付手续费
⑥ 服务商手续费 = 卖家手续费 − 平台交易手续费（仅宝付钱包订单有数据，属历史遗留字段；汇付钱包订单展示 —）
卖家所得 = 买家实付 − 卖家手续费
  • 宝付支付：保留宝付原真实数据，列表字段值与支付渠道后台一致
