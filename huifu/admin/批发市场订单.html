功能说明

一、页面定位

  • 展示平台「批发市场订单」明细，支持按订单编号、用户账号、支付渠道订单号、产品名等维度筛选
  • 覆盖 宝付钱包 与 汇付钱包 两个支付渠道的订单记录

二、字段说明

  • 基础字段：订单编号、支付渠道订单号、产品名称、产品编号、用户账号、认购份数、单价、是否提货、手续费
  • 状态与金额：订单状态（已成交 / 已撤销 / 待支付 / 退款中 / 退款）、实付金额、支付产品、支付渠道、时间、退款时间
  • 支付渠道：宝付 / 汇付，对应"支付产品"银行卡 / 余额
  • 支付产品：原先的"支付渠道"重命名而来（银行卡 / 余额）

三、产品编号

  • 产品名称后新增 产品编号 列
  • 汇付钱包 已成交订单认购份数为 1-90 份，每份对应一个编号（如 #0100、#0101…）
  • 单元格默认最多展示 5 个编号，超出部分以「…等 N 个」提示，鼠标悬停 显示全部编号

四、支付渠道与支付产品

  • 新增 支付渠道 字段：宝付 和 汇付
  • 原先的"支付渠道"改为 "支付产品"（银行卡 / 余额）
  • 二者均支持筛选，并在列表中展示
