功能说明

一、页面定位与字段

  • 展示平台「产品分账」订单明细，含订单、产品、用户、金额与分账结果
  • 字段：订单编号、产品名称、用户账号、数量 / 单价、总价、第三方支付手续费、创建时间、首次分账时间
  • 分账字段：批发商分账、平台分账（上线服务费 / 平台管理服务费 / 补第三方支付手续费）、零售市场分账、剩余金额、零售市场最后分账时间

二、首次分账规则

  • 平台分账（上线服务费）：固定 5%，不变
  • 平台分账（补第三方支付手续费）：固定 0.6%，不变
  • 平台分账（平台管理服务费）：按「最终批发金额」所属档位确定为 10% / 8% / 6% / 5%，详见下方档位规则
  • 批发商分账：基础 40% − 0.6%，加上按档位匹配的增量 0% / 2% / 4% / 5%（与平台管理服务费呈镜像：批发商增量 = 10% − 档位费率）
  • 分账链路仅含「批发商 + 平台」两方，不涉及其他角色

三、批发金额档位规则

  • 系统依据每笔订单的「最终批发金额」匹配以下档位，档位在订单生成时即确定并固化
  • 档位 最终批发金额 平台管理服务费 批发商增量
    A 类 500 万以内 10% 0%
    B 类 500 万 ~ 800 万 8% 2%
    C 类 800 万 ~ 1000 万 6% 4%
    D 类 1000 万以上 5% 5%
  • 批发商实际分账比例 = 40% − 0.6% + 档位增量
  • 档位一经确定不再变更，订单详情与列表均按该档位计算与展示

四、平台分账与批发商分账关系

  • 平台管理服务费随批发金额档位阶梯下调（A→B→C→D：10% → 8% → 6% → 5%）；批发商分账则对应阶梯上调（+0% → +2% → +4% → +5%）
  • 无论档位如何，「批发商分账 + 平台管理服务费」恒为 40% − 0.6% + 10% = 49.4%
  • 批发金额越大，批发商实际分账越多；批发金额越小，平台管理服务费占比越大 —— 二者呈镜像关系

五、计算公式

  • 第三方支付手续费 = 总价 × 0.6%
  • 平台管理服务费 = 总价 × 档位费率（10% / 8% / 6% / 5%）
  • 批发商分账 = 总价 × (40% − 0.6% + 档位增量) = 总价 × (40% − 0.6% + (10% − 档位费率))
  • 平台分账（合计） = 上线服务费 5% + 平台管理服务费 + 补第三方支付手续费 0.6%
  • 零售市场分账总金额 =（总价 − 批发商分账 − 平台分账合计）/ 总数量 × 零售市场分账总数量
  • 剩余金额 = 总价 − 批发商分账 − 平台分账合计 − 零售市场分账总金额
